Membership Inference Analysis

A cybersecurity research project investigating whether machine-learning models reveal information about the data used during their training.

Project image 1
Project image 2

About the project

The project used target models, shadow models and logistic regression to test membership inference attacks. Results were evaluated using accuracy, confusion matrices, ROC curves and AUC scores.

  • Pandas
  • Matplotlib
