About me

I like building software that makes complexity feel simple.

I’m a cybersecurity and software development student with a practical streak: I enjoy designing tools, apps, and workflows that solve real problems without making people wrestle with the technology.

Some of my best work happens when I combine clean product thinking with technical depth—whether that’s a desktop tool for streamlining admin work, a secure mobile app, or a security project that explores how systems leak information. I’m especially interested in secure software development, automation, and building things that are useful first and impressive second.
